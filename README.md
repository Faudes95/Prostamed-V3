# ProstaMed V3

Public, sanitized source snapshot for ProstaMed V3.

This repository intentionally excludes local databases, WAL/SHM files, logs, private runtime outputs, model weights/artifacts, cache folders, screenshots, and PHI-bearing local data. It is intended as a clean source-code backup and development baseline, not as a clinical data backup.

Local operational backup with private/runtime material is kept separately as `Prostamed V3.1.zip` on the workstation desktop.
